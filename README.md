# Discrete Mathematics

Lecture notes, practice sheets, teaching notes, and quizzes for discrete mathematics, maintained by **Mahmoud AboZied**.

The materials cover propositional logic and proofs, sets, induction, relations, functions, recurrence relations, and graphs. Section notes also cover counting and number theory.

## Browse the materials

| Folder | Contents |
| --- | --- |
| [Lectures](lectures/README.md) | Nine numbered topics, lecture PDFs, summaries, and instructional examples |

## Suggested study route

1. Read the [course guide](notes/course-guide.md) and choose a [lecture topic](lectures/README.md).
2. Work through its explanations and instructional examples.
3. Attempt the matching [practice sheets](practice/README.md).
4. Use the [question bank](practice/question-bank.md) for review and the [Quiz 1 models](quizzes/quiz-01/README.md) for timed practice.

## Repository scope

Published assignments and quizzes contain questions, not answer keys. Lecture explanations, theorem proofs, illustrative worked examples, and code examples are retained. Explicit exercise solutions and appended answer sections are excluded.

Typst sources, compiled programs, teacher copies, student records, and private materials are excluded from Git. Local originals are preserved in an ignored `private/` folder. PDF handouts are included intentionally.

Existing author and source credits are retained within the teaching materials. All navigation links are relative so they work on GitHub and in a local clone.
