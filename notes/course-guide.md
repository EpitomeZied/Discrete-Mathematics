## The subject in one line

The course is not a list of formulas. It is **learning to write an argument someone else cannot poke a hole in** — and every topic (logic, sets, counting, graphs) is practice material for that one skill.

## Arc

Logic → proof methods → induction → sets → functions → relations → counting → recurrences → number theory → graphs/trees → review. Logic is the grammar; everything after it is written in that grammar.
